# 开发者后台-我的工具页面功能增强

## 需求分析

在开发者后台「我的-我的工具」页面中，为**已上架（approved）**的工具卡片增加两个按钮：

1. **进入智能推广中心** - 点击后跳转到智能推广中心，并自动携带工具相关信息
2. **寻求星推官** - 占位按钮，暂时无实际功能

## 当前页面结构

MyTools.tsx 中工具卡片渲染逻辑：
- 工具卡片显示工具名称、描述、状态、分类、提交时间
- 已有操作按钮：查看详情（approved状态）、编辑、删除
- 操作按钮位于卡片右上角

## 智能推广中心分析

PromotionCenter.tsx 页面：
- 路径：`/promotion`
- 功能：AI一键生成多平台推广文案
- 需要工具信息：工具名称、描述、链接等

## 实现方案

### 1. 修改 MyTools.tsx

在已上架工具卡片的操作按钮区域（line 251-278）增加两个新按钮：

**进入智能推广中心按钮：**
- 使用 `Megaphone` 图标（与智能推广中心主题一致）
- 点击后跳转到 `/promotion?toolId=${tool.id}`
- 通过 URL 参数传递工具 ID

**寻求星推官按钮：**
- 使用 `Users` 或 `UserPlus` 图标
- 暂时为占位按钮，点击可弹出提示"功能即将上线"

### 2. 按钮布局调整

当前布局（line 251-278）：
```
[查看详情] [编辑] [删除]
```

新布局（approved状态）：
```
[进入智能推广中心] [寻求星推官] [查看详情] [编辑] [删除]
```

### 3. 按钮样式

- 进入智能推广中心：使用橙色渐变背景（与智能推广中心主题一致）
- 寻求星推官：使用紫色/蓝色渐变背景
- 保持与现有按钮一致的圆角和悬停效果

## 预期效果

- 已上架工具卡片显示两个新按钮
- 点击"进入智能推广中心"跳转到智能推广中心并携带工具ID
- "寻求星推官"按钮为占位，显示功能即将上线提示
