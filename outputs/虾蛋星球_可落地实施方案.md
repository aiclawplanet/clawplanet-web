# 虾蛋星球可落地实施方案

**文档版本**: v2.0
**生成日期**: 2026年4月19日
**实施周期**: 6-8周（完整功能版）
**预算估算**: 2,000-3,000元
**主力载体**: H5移动网站（响应式）
**辅助载体**: 微信小程序（回访入口）

---

## 一、项目目标

### 1.1 核心目标

在6-8周内完成虾蛋星球完整功能版本的开发并上线，包括：
- **食客端（H5）**：工具发现、搜索、分类、收藏
- **虾匠端（H5）**：入驻申请、作品管理、数据看板
- **店小二端（H5）**：推广链接、佣金追踪
- **小程序端**：作为H5的辅助入口，方便用户收藏和回访

### 1.2 成功指标

| 指标 | 目标值 | 时间 |
|------|--------|------|
| 上线工具数 | ≥20个 | 上线时 |
| 日均UV | ≥100 | 上线后1个月 |
| 入驻开发者 | ≥10人 | 上线后2个月 |
| 付费推广工具 | ≥5个 | 上线后3个月 |

## 二、技术架构

### 2.1 技术栈

```
前端（H5）
├── React 18 + TypeScript
├── Tailwind CSS（紫色/蓝色主题）
├── React Router（Hash模式）
├── Framer Motion（动画）
└── Lucide React（图标）

后端（BaaS）
├── Supabase（PostgreSQL + Auth + Storage）
├── Edge Functions（Serverless）
└── Row Level Security（数据安全）

支付
└── 微信支付（H5支付）

部署
└── 静态托管 + Edge Functions
```

### 2.2 数据库设计

#### 核心表结构

```sql
-- 工具表
CREATE TABLE tools (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  description TEXT,
  category TEXT NOT NULL,
  tags TEXT[],
  icon_url TEXT,
  screenshots TEXT[],
  jump_url TEXT NOT NULL, -- 跳转链接
  jump_type TEXT NOT NULL, -- 'miniprogram' | 'h5' | 'app'
  developer_id UUID REFERENCES profiles(id),
  status TEXT DEFAULT 'pending', -- 'pending' | 'approved' | 'rejected'
  is_premium BOOLEAN DEFAULT false,
  price DECIMAL(10,2) DEFAULT 0,
  view_count INTEGER DEFAULT 0,
  jump_count INTEGER DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- 分类表
CREATE TABLE categories (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  icon TEXT,
  sort_order INTEGER DEFAULT 0,
  tool_count INTEGER DEFAULT 0
);

-- 用户表（与auth.users关联）
CREATE TABLE profiles (
  id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  username TEXT UNIQUE,
  avatar_url TEXT,
  role TEXT DEFAULT 'user', -- 'user' | 'developer' | 'promoter' | 'admin'
  created_at TIMESTAMP DEFAULT NOW()
);

-- 订阅表
CREATE TABLE subscriptions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES profiles(id),
  status TEXT DEFAULT 'active', -- 'active' | 'cancelled' | 'expired'
  start_date TIMESTAMP DEFAULT NOW(),
  end_date TIMESTAMP,
  amount DECIMAL(10,2),
  created_at TIMESTAMP DEFAULT NOW()
);

-- 推广链接表
CREATE TABLE promotion_links (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  promoter_id UUID REFERENCES profiles(id),
  tool_id UUID REFERENCES tools(id),
  code TEXT UNIQUE NOT NULL,
  click_count INTEGER DEFAULT 0,
  conversion_count INTEGER DEFAULT 0,
  commission_earned DECIMAL(10,2) DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW()
);

-- 收藏表
CREATE TABLE favorites (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES profiles(id),
  tool_id UUID REFERENCES tools(id),
  created_at TIMESTAMP DEFAULT NOW(),
  UNIQUE(user_id, tool_id)
);
```

## 四、UI/UX设计规范

### 4.1 设计原则

- **科技感**: 深色背景 + 霓虹光效
- **紫色主题**: 主色 #8B5CF6，辅色 #3B82F6
- **卡片化**: 工具以卡片形式展示
- **微交互**: 悬停效果、过渡动画

### 4.2 色彩系统

```css
/* 主色调 */

--primary-dark: #7C3AED;  /* 深紫 */

--secondary-dark: #2563EB; /* 深蓝 */

/* 背景色 */
--bg-dark: #0F0F1A;       /* 深色背景 */
--bg-card: #1A1A2E;       /* 卡片背景 */
--bg-hover: #252542;      /* 悬停背景 */

/* 文字色 */
--text-primary: #FFFFFF;

--success: #10B981;
```

## 八、风险预案

### 8.1 技术风险

| 风险 | 概率 | 应对 |

### 8.2 运营风险

| 风险 | 概率 | 应对 |

| 风险 | 概率 | 应对 |
