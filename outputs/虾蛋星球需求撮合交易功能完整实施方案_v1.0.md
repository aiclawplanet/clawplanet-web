## 第二部分：功能模块详细设计

### 一、一期功能（信息撮合阶段）

#### 1. 需求方功能模块

##### 1.1 需求发布功能

**入口设计：**
- 首页顶部导航栏新增【发布需求】按钮
- 个人中心新增【我的需求】入口

**需求发布表单：**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| 需求标题 | 文本 | 是 | 简短概括，如"小程序记账工具定制" |
| 需求类型 | 单选 | 是 | 小程序开发、网站开发、APP开发、功能二次开发、插件定制、其他 |
| 所属领域 | 下拉 | 是 | 关联平台作品分类，精准匹配开发者 |
| 详细需求 | 富文本 | 是 | 支持图片附件（最多3张） |
| 预算区间 | 单选 | 是 | 500元内、500-2000元、2000-5000元、5000-10000元、10000元以上、面议 |
| 期望周期 | 单选 | 是 | 1周内、1-2周、2-4周、1个月以上、面议 |
| 联系方式 | 文本 | 否 | 手机号/微信（选填，可对接后发送） |
| 实名验证 | 验证 | 是 | 必须完成手机号实名验证 |

**业务流程：**
```
用户填写需求 → 提交审核 → 管理员审核 → 审核通过展示在需求大厅
```

##### 1.2 需求管理功能

**我的需求列表：**
- 状态筛选：待审核、审核通过、对接中、已完成、已关闭
- 操作功能：
  - 查看开发者报价
  - 选择对接开发者
  - 关闭需求
  - 标记需求完成
  - 举报违规报价

**消息提醒：**
- 收到新报价时站内信实时提醒
- 报价被查看时通知开发者

#### 2. 开发者功能模块

##### 2.1 需求大厅功能

**入口设计：**
- 开发者后台新增【需求大厅】导航
- 与【作品管理】【推广管理】并列

**需求展示：**
- 列表/瀑布流布局
- 排序方式：发布时间、需求类型、预算金额
- 筛选条件：需求类型、预算区间、周期、所属领域

**需求详情：**
- 展示完整需求内容
- 隐藏用户隐私联系方式（需通过平台对接）
- 显示已报价人数

##### 2.2 报价接单功能

**报价表单：**

| 字段 | 类型 | 必填 | 说明 |
|-----|------|------|------|
| 报价金额 | 数字 | 是 | 具体报价金额 |
| 交付周期 | 单选 | 是 | 预计完成时间 |
| 对接备注 | 文本 | 否 | 开发方案简述 |

**报价限制：**
- 单个开发者最多同时报价3条需求
- 防止恶意刷屏

**报价管理：**
- 状态：待查看、已对接、已拒绝、已失效
- 报价被查看/对接时站内信提醒

##### 2.3 对接管理功能

**对接成功后：**
- 生成专属对接单
- 在线留言沟通功能
- 查看需求方基础信息

#### 3. 平台管理员功能模块

##### 3.1 需求审核管理

- 待审核需求列表
- 审核操作：通过、驳回（需填写原因）
- 违规处理：清理垃圾需求、封禁违规账号

##### 3.2 报价管理

- 查看所有开发者报价
- 过滤恶意低价/高价报价
- 删除违规报价

##### 3.3 数据统计

- 需求发布量、报价量、对接成功量
- 按需求类型、领域统计供需数据

##### 3.4 规则配置

- 需求发布规则
- 报价规则
- 对接规范
- 用户协议、风险提示文案

### 二、二期功能（效率提升阶段）

#### 2.1 即时沟通系统

- 无需跳转第三方工具

#### 2.4 开发者信誉体系

### 三、三期功能（商业化阶段）

#### 3.1 平台担保交易

- 里程碑付款
- 交易安全保障

#### 3.2 开发进度同步

## 第四部分：合规风险提示

### 一、一期开发合规要点

✅ **可以安全开展：**
- 信息撮合服务属于"信息技术咨询服务"，在经营范围内
- 仅提供信息展示和对接，不涉及资金流转
- 明确平台仅为信息撮合方，不参与实际开发交易

⚠️ **需要注意：**
- 前端必须展示风险提示文案
- 用户协议需明确平台责任边界
- 禁止承诺交易结果或开发质量

### 二、三期开发资质要求

❌ **不可直接开展：**
- 资金托管属于"在线数据处理与交易处理业务"
- 需要办理 **ICP经营许可证**

📋 **ICP经营许可证办理条件：**
1. 经营者为依法设立的公司（个体工商户较难申请）
2. 有与开展经营活动相适应的资金和专业人员
3. 有为用户提供长期服务的信誉或能力
4. 注册资本最低限额为100万元人民币
5. 有必要的场地、设施及技术方案
6. 公司及其主要出资者和主要经营管理人员三年内无违反电信监督管理制度的违法记录

💡 **建议方案：**
- 一期、二期先以个体工商户身份运营
- 三期前注册公司，办理ICP经营许可证
- 或三期功能采用第三方担保支付（如支付宝担保交易）

```
【风险提示】
```

```
第X条 交易风险
用户应自行判断交易对方的履约能力和信用状况，平台不对任何交易风险承担责任。建议用户签订正式合同，通过正规渠道进行资金往来。
```
