# 虾蛋星球微信生态域名风险分析

**分析日期**: 2026年4月19日  
**主域名**: aiclawplanet.com  
**分析目标**: 评估在微信生态内使用的潜在风险

---

## 一、微信生态域名管理规则

### 1.1 微信对外部链接的管理

微信对外部域名的主要限制：

| 限制类型 | 说明 | 影响 |
|----------|------|------|
| **域名备案** | 必须完成ICP备案 | 未备案域名无法在微信内打开 |
| **HTTPS** | 必须使用HTTPS | HTTP链接会被拦截 |
| **违规内容** | 涉及违规会被封禁 | 整个域名被微信屏蔽 |
| **诱导分享** | 禁止强制分享 | 可能被封禁 |
| **欺诈/钓鱼** | 禁止欺诈行为 | 永久封禁 |

### 1.2 域名本身的风险因素

| 风险因素 | 说明 | aiclawplanet.com 情况 |
|----------|------|----------------------|
| **域名后缀** | 某些后缀被限制 | .com 国际通用，无限制 |
| **域名历史** | 域名曾被用于违规 | 新注册域名，无历史 |
| **关键词敏感** | 含敏感词汇 | "ai" "claw" "planet" 均不敏感 |
| **品牌冲突** | 与知名品牌冲突 | 无直接冲突 |
