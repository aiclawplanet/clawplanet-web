# 一、平台概述
## 1.1 平台定位
虾蛋星球是一个专注于独立开发者生态的综合性服务平台，致力于连接独立开发者与潜在用户，同时为开发需求方提供高效的需求撮合服务。平台通过工具导航、智能推广、需求撮合三大核心业务，构建完整的独立开发者服务生态。
## 1.2 核心价值主张
• 对开发者：提供作品展示平台，获取精准流量，实现商业化变现
• 对用户：发现优质独立开发工具，满足个性化需求
• 对需求方：快速找到合适开发者，降低寻找成本
• 对推广者：通过推广优质工具赚取佣金，实现流量变现
## 1.3 平台数据概览
• 注册用户：持续增长中
• 入驻开发者：审核制入驻，保证质量
• 工具数量：覆盖多品类独立开发工具
• 需求撮合：一期二期功能已上线

# 二、核心功能模块
## 2.1 工具导航平台
【功能描述】
为独立开发者提供作品展示和分发渠道，用户可以通过分类、搜索、推荐等方式发现优质工具。
【核心功能】
• 工具分类浏览：按效率工具、生活助手、开发工具等分类展示
• 智能搜索：支持关键词搜索、标签筛选
• 个性化推荐：基于用户行为的智能推荐算法
• 工具详情页：展示工具介绍、截图、开发者信息、用户评价
• 收藏功能：用户可收藏感兴趣的工具
• 浏览历史：记录用户浏览过的工具
## 2.2 智能推广系统
【功能描述】
为入驻开发者提供一站式推广解决方案，通过AI生成推广内容，支持多平台一键发布。
【核心功能】
• AI文案生成：基于工具信息自动生成推广文案
• 多平台发布：支持微信公众号、知乎、小红书等平台
• 推广链接生成：带追踪参数的推广链接
• 数据统计：点击量、转化率等数据追踪
• 星推官体系：招募推广者帮助推广，按效果付费
## 2.3 需求撮合系统（一期二期已上线）
【功能描述】
连接有开发需求的用户与独立开发者，提供从需求发布到对接完成的全流程服务。
【一期功能 - 信息撮合】
• 需求发布：用户可发布网站开发、APP开发、小程序开发等需求
• 需求大厅：开发者可浏览需求并报价
• 报价系统：开发者提交报价，需求方选择合适开发者
• 我的需求/报价管理：双方管理自己的需求和报价
• 审核机制：平台审核需求，保证质量
【二期功能 - 效率提升】
• 即时沟通：需求方与开发者在线聊天，无需跳转第三方
• 需求置顶：付费置顶服务，增加曝光量
• 开发者信誉：等级体系、评分系统、历史评价
• 星推官推广：推广需求撮合订单，赚取佣金

# 三、用户角色体系
## 3.1 普通用户
【权限功能】
• 浏览工具导航，搜索发现工具
• 收藏工具，查看浏览历史
• 发布开发需求（需手机验证）
• 查看报价，选择开发者
• 与开发者在线沟通
• 评价开发者
## 3.2 入驻开发者
【入驻条件】
• 提交开发者申请，通过平台审核
• 提供真实身份信息和作品案例
【权限功能】
• 提交工具产品，获得展示位
• 浏览需求大厅，查看需求详情
• 对需求进行报价
• 管理报价，查看报价状态
• 与需求方在线沟通
• 查看开发者后台数据（浏览量、点击量等）
• 使用智能推广系统
• 积累信誉等级和评价
## 3.3 星推官
【入驻条件】
• 提交星推官申请，通过平台审核
• 具备一定粉丝基础或推广能力
【权限功能】
• 生成工具推广链接，赚取推广佣金
• 推广需求撮合订单，赚取撮合佣金
• 查看推广数据统计
• 申请佣金提现
## 3.4 平台管理员
【权限功能】
• 审核开发者入驻申请
• 审核需求发布
• 管理工具上下架
• 查看平台运营数据
• 处理用户反馈和投诉

# 四、页面功能详解
## 4.1 首页
【入口路径】/
【功能模块】
• 轮播Banner：展示平台核心功能和推广位
• 分类导航：快速进入各工具分类
• 搜索框：支持关键词搜索
• 精选工具：编辑推荐优质工具
• 最新上架：展示最新入驻的工具
• 热门榜单：按浏览量/点击量排序
• 个性化推荐：基于用户兴趣推荐
## 4.2 工具详情页
【入口路径】/tool/:id
【功能模块】
• 工具基本信息：名称、图标、描述、标签
• 截图展示：工具界面截图轮播
• 开发者信息：开发者简介、其他作品
• 操作按钮：访问官网、收藏、分享
• 用户评价：展示用户评论和评分
• 相关推荐：同类工具推荐
## 4.3 需求大厅
【入口路径】/demands
【功能模块】
• 需求列表：瀑布流/列表展示所有已审核需求
• 筛选功能：按类型、预算、周期筛选
• 排序功能：按时间、预算排序
• 搜索功能：关键词搜索需求
• 发布入口：快速发布新需求
## 4.4 需求详情页
【入口路径】/demand/:id
【功能模块】
• 需求信息：标题、类型、预算、周期、详细描述
• 需求方信息：匿名展示，保护隐私
• 报价列表（需求方可见）：查看所有报价
• 报价按钮（开发者）：提交报价
• 联系按钮：创建聊天会话
## 4.5 消息中心
【入口路径】/chat
【功能模块】
• 会话列表：展示所有聊天会话
• 未读标识：显示未读消息数量
• 聊天页面：实时消息收发、已读状态
• 会话创建：通过需求详情页创建
## 4.6 个人中心
【入口路径】/profile
【功能模块】
• 用户信息：头像、昵称、角色标识
• 功能入口：我的需求、我的报价、消息中心
• 开发者入口：开发者后台、需求大厅（开发者）
• 星推官入口：推广中心
• 收藏管理：我的收藏
• 设置：账号设置、退出登录
## 4.7 开发者后台
【入口路径】/dashboard
【功能模块】
• 数据统计：工具数量、总浏览量、总点击量
• 流量趋势：近7天数据图表
• 工具管理：添加新工具、编辑工具信息
• 快捷入口：需求大厅、我的报价

# 五、技术架构
## 5.1 前端技术栈
• 框架：React 18 + TypeScript
• 构建工具：Webpack 5
• 样式：Tailwind CSS
• 路由：React Router（Hash模式）
• 动画：Framer Motion
• 图表：Recharts
## 5.2 后端服务
• 数据库：PostgreSQL（Supabase）
• 认证：Supabase Auth
• 存储：Supabase Storage
• 实时：Supabase Realtime
• 边缘函数：Deno TypeScript
## 5.3 数据库表结构
• profiles：用户资料表
• tools：工具信息表
• categories：分类表
• demands：需求表
• quotes：报价表
• chat_conversations：聊天会话表
• chat_messages：聊天消息表
• developer_reputation：开发者信誉表
• reviews：评价表
• promotion_links：推广链接表
• promoters：星推官表
