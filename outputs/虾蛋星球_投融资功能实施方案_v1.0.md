## 一、项目概述

### 1.1 背景
虾蛋星球作为"中国版Product Hunt"，已具备工具展示、开发者入驻、用户社区等核心功能。为进一步提升平台价值，建立投融资渠道，帮助优秀独立开发项目对接资本，同时为平台自身创造新的变现路径。

### 1.2 目标
- **短期**: 建立轻量级融资信息展示功能，验证市场需求
- **中期**: 打造"虾蛋星选"品牌，建立项目筛选和背书机制
- **长期**: 构建完整的开发者投融资生态，平台实现多元化盈利

### 1.3 核心价值主张
> **"让每个好项目，遇见懂它的投资人"**

## 二、三阶段实施方案

### 第一阶段：融资需求展示（轻量级验证）

**时间周期**: 2-3周  
**投入成本**: 低（仅前端+数据库改动）  
**核心目标**: 验证开发者融资需求真实存在

#### 2.1.1 功能设计

**开发者端 - 融资信息设置**
```
位置: 开发者后台 → 我的工具 → 融资设置

字段:
├── 融资状态: 未融资 / 正在融资 / 融资关闭
├── 融资阶段: 种子轮 / 天使轮 / Pre-A / A轮 / 战略融资
├── 融资金额: 50万 / 100万 / 300万 / 500万 / 1000万+ / 面议
├── 资金用途: 多选（产品研发/市场推广/团队扩张/运营资金）
├── 已融金额: 可选填写（展示进度）
├── 融资亮点: 200字以内项目亮点
├── 联系方式: 邮箱/微信（仅认证投资人可见）
└── 商业计划书: 可选上传（PDF，仅认证投资人可下载）
```

**用户端 - 融资标签展示**
```
位置1: 工具卡片 - 显示"融资中"角标
位置2: 工具详情页 - 顶部显示融资信息横幅
位置3: 新增"找投资"筛选标签

展示内容:
├── 融资阶段标签（种子轮/天使轮等）
├── 目标金额范围
├── 融资进度条（已融/目标）
├── "联系创始人"按钮（需登录+认证投资人身份）
└── 项目亮点摘要
```

#### 2.1.2 数据库设计

```sql
-- 工具融资信息表
CREATE TABLE tool_funding (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tool_id UUID REFERENCES tools(id) ON DELETE CASCADE NOT NULL,
  developer_id UUID REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL,
  
  -- 融资状态
  status VARCHAR(20) DEFAULT 'not_funding' CHECK (status IN ('not_funding', 'funding', 'closed')),
  stage VARCHAR(20) CHECK (stage IN ('seed', 'angel', 'pre_a', 'a', 'strategic')),
  
  -- 金额信息
  target_amount_min INTEGER, -- 单位：万元
  target_amount_max INTEGER,
  raised_amount INTEGER DEFAULT 0,
  
  -- 资金用途（多选存储为数组）
  fund_usage TEXT[], -- ['product', 'marketing', 'team', 'operation']
  
  -- 项目亮点
  highlights TEXT,
  
  -- 联系方式（加密存储）
  contact_email VARCHAR(255),
  contact_wechat VARCHAR(100),
  
  -- 商业计划书
  pitch_deck_url TEXT,
  
  -- 时间戳
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  
  UNIQUE(tool_id)
);

-- 投资人认证表
CREATE TABLE investor_verification (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL,
  
  -- 认证类型
  type VARCHAR(20) CHECK (type IN ('individual', 'institution')),
  
  -- 个人信息
  real_name VARCHAR(100),
  company_name VARCHAR(200),
  title VARCHAR(100),
  
  -- 投资偏好
  preferred_stages TEXT[], -- ['seed', 'angel', 'pre_a']
  preferred_fields TEXT[], -- ['ai', 'saas', 'consumer']
  
  -- 认证材料
  id_card_url TEXT,
  business_card_url TEXT,
  
  -- 审核状态
  status VARCHAR(20) DEFAULT 'pending' CHECK (status IN ('pending', 'approved', 'rejected')),
  verified_at TIMESTAMP,
  
  created_at TIMESTAMP DEFAULT NOW(),
  UNIQUE(user_id)
);

-- 投资意向记录表
CREATE TABLE investment_intent (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tool_id UUID REFERENCES tools(id) ON DELETE CASCADE NOT NULL,
  investor_id UUID REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL,
  developer_id UUID REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL,
  
  status VARCHAR(20) DEFAULT 'pending' CHECK (status IN ('pending', 'contacted', 'meeting', 'passed', 'invested')),
  message TEXT, -- 投资人留言
  
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

#### 2.1.3 RLS安全策略

```sql
-- 融资信息：所有人可查看公开的融资信息
CREATE POLICY "公开融资信息可查看" ON tool_funding
FOR SELECT USING (status = 'funding');

-- 融资信息：开发者可管理自己的融资信息
CREATE POLICY "开发者可管理自己的融资信息" ON tool_funding
FOR ALL USING (developer_id = auth.uid());

-- 投资人认证：仅管理员可审核
CREATE POLICY "用户可查看自己的认证状态" ON investor_verification
FOR SELECT USING (user_id = auth.uid());

-- 投资意向：双方可查看
CREATE POLICY "投资双方可查看意向记录" ON investment_intent
FOR SELECT USING (investor_id = auth.uid() OR developer_id = auth.uid());
```

### 第二阶段：虾蛋星选（平台背书）

**时间周期**: 4-6周  
**投入成本**: 中（需要运营+产品）  
**核心目标**: 建立平台品牌，实现服务变现

#### 2.2.1 核心功能

**1. 星选项目评选机制**
```
评选周期: 每月一次
评选数量: 10个项目/期
评选标准:
├── 产品完成度 (30%) - 可用性、用户体验
├── 市场潜力 (25%) - TAM、竞争格局
├── 团队背景 (20%) - 开发者履历、执行力
├── 数据表现 (15%) - 用户增长、留存
└── 创新性 (10%) - 差异化、技术壁垒

评选流程:
开发者报名 → 初筛 → 平台评审 → 入选公示 → 专题推广
```

**2. 星选项目权益**
```
入选权益:
├── 首页Banner展示位（7天）
├── "虾蛋星选"认证徽章
├── 专属项目详情页模板
├── 平台官方推荐语
├── 投资人定向推送
├── 社群专属曝光
└── 可选：平台跟投机会

收费标准:
├── 基础入选：免费
├── 推广套餐：¥2999/期（含Banner+推送）
└── 深度服务：¥9999/期（含BP辅导+投资人对接）
```

**3. 投资人服务**
```
投资人端功能:
├── 星选项目优先查看权
├── 项目集PDF下载
├── 线上路演参与资格
├── 1v1项目对接服务
└── 投资案例展示墙

投资人分级:
├── 普通认证投资人（免费）
├── 星级投资人（累计投资3个项目）
└── 战略投资人（机构背景，定向邀请）
```

### 第三阶段：生态闭环（深度参与）

**时间周期**: 3-6个月  
**投入成本**: 高（需要法务+资金）  
**核心目标**: 构建完整投融资生态，平台成为核心节点

#### 2.3.1 核心功能

**1. 虾蛋跟投基金**
```
基金定位: 早期项目跟投基金
基金规模: 起步500万，目标3000万
投资阶段: 种子轮-天使轮
单笔投资: 10-50万
决策机制: 领投人确定后，基金自动跟投

收益分配:
├── 项目退出收益：基金80% + 平台20%
├── 跟投服务费：向领投人收取5%
└── 管理费：年化2%

合规要求:
├── 私募基金管理人牌照（或挂靠）
├── 合格投资人认定
└── 基金备案
```

**2. 线上路演系统**
```
功能模块:
├── 项目直播路演
├── 投资人问答互动
├── 意向投资实时统计
├── 会后1v1预约
└── 路演回放存档

收费模式:
├── 项目方：¥5000/场
├── 投资人：免费
└── 平台抽成：成功融资额的1%
```

**3. 数据服务**
```
产品形态:
├── 《早期独立开发投资趋势报告》（季度）
├── 热门赛道分析
├── 项目估值参考
└── 投资人行为洞察

销售渠道:
├── 机构订阅：¥10万/年
├── 单次报告：¥5000/份
└── 定制分析：¥5万/起
```

## 四、风险与应对

### 4.1 合规风险

| 风险 | 等级 | 应对 |
|------|------|------|
| 非法集资嫌疑 | 高 | 仅做信息撮合，不经手资金 |

### 4.2 运营风险

| 风险 | 等级 | 应对 |
|------|------|------|
| 虚假融资信息 | 中 | 人工审核+举报机制 |
| 投资人质量差 | 中 | 实名认证+资质审核 |
| 撮合成功率低 | 低 | 降低预期，先做信息展示 |

### 6.2 关键指标定义

- **融资成功率**: 成功获得投资的项目数 / 发布融资需求的项目数
- **投资人活跃度**: 月均发起投资意向数 / 认证投资人总数
- **撮合效率**: 从意向到首次接触的平均天数
- **平台收入**: 投融资相关服务收入（不含推广服务）
