# 虾蛋星球智能推广系统方案 v1.0

**文档版本**: 1.0  
**创建日期**: 2026年4月19日  
**面向对象**: 老赵（虾蛋星球创始人 + WorkBuddy小程序开发者）

---

## 一、需求分析

### 1.1 老赵的核心痛点

| 痛点 | 描述 | 影响 |
|------|------|------|
| 文案创作耗时 | 每次推广都要写不同平台的文案 | 效率低，难以坚持 |
| 平台适配困难 | 公众号/小红书/即刻/知乎风格不同 | 同一内容要改多版 |
| 发布管理混乱 | 不知道哪些发了哪些没发 | 容易遗漏或重复 |
| 效果难以追踪 | 发出去不知道效果如何 | 无法优化迭代 |

### 1.2 目标场景

1. **虾蛋星球推广**: 新功能上线、星选项目发布、活动招募
2. **WorkBuddy推广**: 小程序新功能、使用教程、用户案例

### 2.2 核心功能模块

#### 模块1: 智能文案生成

**输入方式**:
```
方式1: 一句话描述
输入: "虾蛋星球上线了投融资功能"

方式2: 结构化输入
├── 推广主题: 虾蛋星选第1期发布
├── 核心亮点: 10个优质项目入选
├── 目标受众: 投资人、开发者
├── 期望风格: 专业、有温度
└── 重点平台: 公众号+即刻

方式3: 链接自动解析
输入: https://aiclawplanet.com/tool/xxx
自动提取: 工具名称、功能介绍、开发者故事
```

**AI生成策略**:
```
生成流程:
1. 分析输入内容 → 提取关键信息
2. 匹配平台风格 → 选择对应模板
3. 生成多版本 → 长文/短文/标题
4. 优化润色 → 调整语气、添加emoji

输出示例（虾蛋星球）:
├── 公众号长文版（1500字，深度解读）
├── 小红书笔记版（300字+表情，种草风格）
├── 即刻动态版（100字，极简短平快）
├── 知乎回答版（800字，专业分析）
├── 朋友圈文案版（50字，社交分享）
├── 微博短文案版（140字，热点话题）
├── 掘金技术版（600字，开发者视角）
└── GitHub版（英文，开源社区风格）
```

**模板库**:
```
按场景分类:
├── 新功能上线
│   ├── 模板A: 故事型（从痛点到解决方案）
│   ├── 模板B: 数据型（用数字说话）
│   └── 模板C: 对话型（模拟用户问答）
├── 项目推荐
│   ├── 模板D: 开发者故事型
│   ├── 模板E: 功能亮点型
│   └── 模板F: 用户案例型
├── 活动招募
│   ├── 模板G: 紧迫感型（限时限量）
│   ├── 模板H: 价值型（能获得什么）
│   └── 模板I: 社交型（和谁一起）
└── 数据报告
    ├── 模板J: 榜单型
    ├── 模板K: 趋势型
    └── 模板L: 洞察型
```

## 三、技术实现方案

### 3.1 两种实现路径

#### 方案A: 集成到虾蛋星球（推荐）

**优势**:
- 与现有系统打通，数据共享
- 开发者可以直接使用
- 形成产品差异化

**实现方式**:
```
在虾蛋星球新增模块:
├── 开发者后台 → 推广中心
│   ├── 我的推广
│   ├── 创建推广
│   ├── 推广数据
│   └── 素材库
└── 管理后台 → 推广管理
    ├── 内容审核
    ├── 发布管理
    └── 数据报表
```

**AI能力接入**:
- 使用阿里云大模型API生成文案
- 或使用Edge Function调用AI服务

#### 方案B: 独立工具（WorkBuddy插件）

**优势**:
- 独立产品，可服务更多用户
- 不依赖虾蛋星球开发进度
- 可作为WorkBuddy的增值服务

**实现方式**:
```
WorkBuddy小程序新增:
├── 推广助手页面
│   ├── 文案生成
│   ├── 我的内容
│   ├── 发布管理
│   └── 数据看板
└── 与虾蛋星球打通
    ├── 一键导入虾蛋星球项目
    └── 数据回传虾蛋星球
```

### 3.2 数据库设计

```sql
-- 推广内容表
CREATE TABLE promotion_contents (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL,
  
  -- 基础信息
  title VARCHAR(200) NOT NULL,
  source_type VARCHAR(20) CHECK (source_type IN ('manual', 'ai_generate', 'import')),
  source_id UUID, -- 关联的工具ID或外部链接
  
  -- 内容数据
  content JSONB NOT NULL, -- 存储各平台版本 {wechat: "...", xiaohongshu: "..."}
  
  -- 素材
  images TEXT[], -- 图片URL数组
  videos TEXT[], -- 视频URL数组
  
  -- 标签
  tags TEXT[],
  category VARCHAR(50),
  
  -- 状态
  status VARCHAR(20) DEFAULT 'draft' CHECK (status IN ('draft', 'reviewing', 'approved', 'rejected', 'scheduled', 'publishing', 'published', 'archived')),
  
  -- 排期
  scheduled_at TIMESTAMP,
  published_at TIMESTAMP,
  
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- 发布记录表
CREATE TABLE promotion_publish_logs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  content_id UUID REFERENCES promotion_contents(id) ON DELETE CASCADE NOT NULL,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL,
  
  -- 发布信息
  platform VARCHAR(50) NOT NULL, -- wechat, xiaohongshu, jike, zhihu, etc.
  platform_post_id VARCHAR(100), -- 平台返回的帖子ID
  platform_url TEXT, -- 发布后的链接
  
  -- 状态
  status VARCHAR(20) DEFAULT 'pending' CHECK (status IN ('pending', 'success', 'failed', 'cancelled')),
  error_message TEXT,
  
  -- 时间
  scheduled_at TIMESTAMP,
  executed_at TIMESTAMP,
  
  created_at TIMESTAMP DEFAULT NOW()
);

-- 推广数据表
CREATE TABLE promotion_analytics (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  content_id UUID REFERENCES promotion_contents(id) ON DELETE CASCADE NOT NULL,
  publish_log_id UUID REFERENCES promotion_publish_logs(id) ON DELETE CASCADE NOT NULL,
  
  -- 平台数据
  platform VARCHAR(50) NOT NULL,
  
  -- 基础指标
  impressions INTEGER DEFAULT 0, -- 曝光量
  views INTEGER DEFAULT 0, -- 阅读量
  likes INTEGER DEFAULT 0, -- 点赞
  comments INTEGER DEFAULT 0, -- 评论
  shares INTEGER DEFAULT 0, -- 分享
  collections INTEGER DEFAULT 0, -- 收藏
  
  -- 转化指标
  clicks INTEGER DEFAULT 0, -- 点击链接
  uv INTEGER DEFAULT 0, -- 独立访客
  registrations INTEGER DEFAULT 0, -- 注册数
  
  -- 数据更新时间
  data_updated_at TIMESTAMP DEFAULT NOW(),
  created_at TIMESTAMP DEFAULT NOW(),
  
  UNIQUE(content_id, platform)
);

-- 素材库表
CREATE TABLE promotion_assets (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE NOT NULL,
  
  -- 素材信息
  name VARCHAR(200),
  type VARCHAR(20) CHECK (type IN ('image', 'video', 'text', 'link')),
  url TEXT,
  content TEXT, -- 文本素材的内容
  
  -- 元数据
  tags TEXT[],
  usage_count INTEGER DEFAULT 0,
  
  created_at TIMESTAMP DEFAULT NOW()
);

-- 文案模板表
CREATE TABLE promotion_templates (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  
  -- 模板信息
  name VARCHAR(200) NOT NULL,
  description TEXT,
  category VARCHAR(50), -- 新功能上线、项目推荐等
  
  -- 模板内容
  content TEXT NOT NULL, -- 模板文本，含变量占位符
  variables JSONB, -- 变量定义 [{name: "toolName", description: "工具名称"}]
  
  -- 适用平台
  platforms TEXT[], -- ['wechat', 'xiaohongshu', ...]
  
  -- 系统模板/用户自定义
  is_system BOOLEAN DEFAULT false,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  
  -- 使用统计
  usage_count INTEGER DEFAULT 0,
  
  created_at TIMESTAMP DEFAULT NOW()
);
```

### 3.3 AI文案生成流程

```
用户输入 → 内容分析 → 模板匹配 → 多平台生成 → 优化润色 → 输出结果

详细流程:
1. 用户输入
   └── 主题/链接/结构化数据

2. 内容分析（Edge Function）
   ├── 提取关键信息（工具名、功能、亮点）
   ├── 识别内容类型（新功能/项目推荐/活动）
   └── 分析目标受众

3. 模板匹配
   ├── 根据内容类型选择模板
   ├── 根据受众选择语气风格
   └── 根据平台选择格式

4. 多平台生成（调用AI）
   ├── 生成公众号版本（长文）
   ├── 生成小红书版本（短+emoji）
   ├── 生成即刻版本（极简）
   ├── 生成知乎版本（专业）
   └── 生成朋友圈版本（短句）

5. 优化润色
   ├── 检查敏感词
   ├── 优化标题吸引力
   ├── 添加CTA（行动号召）
   └── 插入相关链接

6. 输出
   └── 返回各平台文案+配图建议
```
