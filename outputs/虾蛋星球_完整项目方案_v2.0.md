## 一、项目概述

### 1.1 一句话定位

> **虾蛋星球是一个独立开发者作品展示与社区交流平台，连接「虾匠」（开发者）与「食客」（用户），通过工具展示、开发者故事、用户反馈和社区互动，让独立开发者的作品被真正需要的人发现、使用和讨论。**

### 1.2 三大角色定义

| 角色 | 定义 | 核心诉求 | 获得回报 |
|------|------|----------|----------|
| 🦐 **虾匠** | 独立开发者（小程序/H5/Web工具创作者） | 作品被需要的人发现 | 免费曝光 + 数据看板 + 可选推广服务 |
| 👨‍🍳 **店小二** | 博主/KOL/社群推广者 | 优质工具带货变现 | 推广分佣 + 专属数据看板 |
| 🍽️ **食客** | 普通用户（工具消费者） | 快速找到实用工具 | 精品导航 + 场景化发现 + 无广告体验 |

### 1.3 核心价值主张

| 对象 | 价值主张 |
|------|----------|
| **对开发者** | "让你的作品被真正需要的人发现，零门槛入驻，数据透明可查" |
| **对用户** | "发现实用工具的宝藏星球，场景化推荐，一键即用" |
| **对推广者** | "推广好工具，赚取透明佣金，数据实时可查" |

### 1.4 项目目标

**短期目标（3个月）**:
- 入驻开发者 ≥50人
- 上架工具 ≥100个
- 日UV ≥500
- 付费推广工具 ≥5个

**中期目标（6个月）**:
- 入驻开发者 ≥200人
- 上架工具 ≥500个
- 日UV ≥2,000
- 平台月收入 ≥5,000元

**长期目标（12个月）**:
- 成为中国最大的独立开发者工具分发平台
- 建立开发者社区生态
- 实现盈亏平衡并盈利

## 二、市场分析

### 2.1 市场规模

| 指标 | 数据 | 说明 |
|------|------|------|
| 中国程序员总数 | ~800万 | 工信部数据 |
| 独立开发者占比 | ~5% | 行业估算 |
| 潜在独立开发者 | ~40万 | 计算得出 |
| 活跃独立开发者 | ~10万 | 行业估算 |
| 年均新增工具数 | ~20万个 | 估算 |
| 潜在市场规模 | ~2,000万元/年 | 推广服务市场 |

### 2.2 市场机会

**应用商店的结构性空白**:
- 搜索关键词不匹配：用户想"算房贷"，不知道搜什么APP
- 小众工具难被发现：应用商店头部效应严重
- 无微信生态工具：应用商店搜不到微信小程序
- 无开发者故事：应用商店只有功能介绍，无温度

**现有分发渠道的缺陷**:
- Product Hunt：无微信生态，无中文本土化
- 新趣集：无变现体系，无IP确权
- w2solo：仅社区内曝光，无独立平台
- 小红书：非垂直分发，工具属性弱

### 2.3 竞品分析

| 竞品 | 类型 | 核心功能 | 虾蛋星球差异化 |
|------|------|----------|---------------|
| Product Hunt | 国际产品发现社区 | 产品首发、投票 | 无微信生态，无分佣 |
| 新趣集 | 类PH中文平台 | 产品提交、点赞 | 无变现体系 |
| w2solo | 独立开发者社区 | 话题讨论 | 无分发闭环 |
| 少数派 | 科技媒体 | 文章、工具推荐 | 编辑主导，非UGC |
| 应用商店 | 应用分发 | APP下载 | 无小程序，无场景推荐 |

### 2.4 五大差异化护城河

1. **微信生态原生闭环**：H5一键跳转小程序，完整使用链路
2. **场景化发现**：从"关键词搜索"到"场景推荐"
3. **轻量即开即用**：无需下载安装，一键使用
4. **轻量级数字IP确权**：时间戳+哈希+证书，保护开发者权益
5. **开发者社区交流**：用户反馈+开发者回复，形成互动

## 三、商业模式

### 3.1 核心原则

> **"先让开发者赚钱，平台再从中分润"**

### 3.2 收入来源

#### 收入一：推广服务费（核心收入）

开发者付费购买平台的推广服务，平台帮助其获取更多用户。

| 服务等级 | 价格 | 权益 |
|----------|------|------|
| 基础展示 | 免费 | 标准展示位，参与自然排序 |
| 首页推荐 | 99元/周 | 首页精品位展示7天 |
| 分类置顶 | 199元/周 | 分类页置顶展示7天 |
| 搜索优先 | 299元/月 | 搜索结果优先展示 |
| 全站推广 | 999元/月 | 首页+分类+搜索全渠道曝光 |

**开发者付费理由**:
- 明码标价，效果可预期
- 比抖音/微信广告便宜（CPM 20-30元 vs 50-100元）
- 用户精准（都是来找工具的人）
- 按效果付费，风险可控

#### 收入二：交易佣金（增量收入）

对于支持内购的工具，从通过虾蛋星球带来的付费用户中抽成。

| 场景 | 分成比例 | 说明 |
|------|----------|------|
| 工具内购 | 5%-10% | 通过虾蛋星球跳转后产生的付费 |
| 会员订阅 | 5%-10% | 同上 |

**合理性**:
- 只有带来真实收益才抽成
- 比例远低于应用商店（苹果30%，安卓50%）

#### 收入三：数据服务（增值服务）

| 服务 | 价格 | 内容 |
|------|------|------|
| 基础数据 | 免费 | PV/UV/跳转数 |
| 用户画像 | 99元/月 | 用户地域/设备/行为分析 |
| 竞品分析 | 199元/月 | 同类工具数据对比 |
| 行业报告 | 499元/份 | 垂直领域趋势报告 |

#### 收入四：企业定制（大客户）

| 客户类型 | 服务 | 价格 |
|----------|------|------|
| 企业客户 | 内部工具导航站定制 | 5,000元/年起 |
| 培训机构 | 学员作品展示平台 | 3,000元/年起 |

## 四、产品方案

### 4.1 载体策略

**主力载体：H5移动网站（响应式）**
- 用户获取最容易（链接分享）
- 开发成本最低（一套代码多端适配）
- 迭代速度最快（无需审核）
- SEO可获取流量（百度搜索收录）

**辅助载体：微信小程序**
- 用户收藏和回访入口
- 微信首页下拉即开
- 核心功能复用H5

**后期可选：PC网站**
- 开发者管理后台
- 等用户量起来后再考虑

### 4.2 核心功能模块

#### 食客端（用户端）

| 页面 | 路径 | 功能 |
|------|------|------|
| 首页 | / | 分类导航、搜索、精品推荐、今日新上架 |
| 分类页 | /category/:id | 分类筛选、工具列表、排序选项 |
| 工具详情 | /tool/:id | 截图轮播、功能介绍、**开发者故事**、一键跳转、收藏、**评论区** |

### 5.2 数据库设计

#### 核心表结构

```sql
-- 工具表
CREATE TABLE tools (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  description TEXT,
  developer_story TEXT, -- 开发者故事
  category TEXT NOT NULL,
  tags TEXT[],
  icon_url TEXT,
  screenshots TEXT[],
  jump_url TEXT NOT NULL,
  jump_type TEXT NOT NULL, -- 'miniprogram' | 'h5' | 'app'
  developer_id UUID REFERENCES profiles(id),
  status TEXT DEFAULT 'pending',
  is_premium BOOLEAN DEFAULT false,
  view_count INTEGER DEFAULT 0,
  jump_count INTEGER DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- 轻量级IP确权表
CREATE TABLE tool_certificates (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tool_id UUID REFERENCES tools(id) ON DELETE CASCADE,
  certificate_code TEXT UNIQUE NOT NULL, -- 唯一确权编码
  hash_value TEXT NOT NULL, -- SHA-256哈希值
  timestamp TIMESTAMP NOT NULL, -- 时间戳
  certificate_url TEXT, -- 证书下载链接
  created_at TIMESTAMP DEFAULT NOW()
);

-- 分类表
CREATE TABLE categories (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  icon TEXT,
  sort_order INTEGER DEFAULT 0,
  tool_count INTEGER DEFAULT 0
);

-- 用户表
CREATE TABLE profiles (
  id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  username TEXT UNIQUE,
  avatar_url TEXT,
  role TEXT DEFAULT 'user',
  created_at TIMESTAMP DEFAULT NOW()
);

-- 收藏表
CREATE TABLE favorites (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES profiles(id),
  tool_id UUID REFERENCES tools(id),
  created_at TIMESTAMP DEFAULT NOW(),
  UNIQUE(user_id, tool_id)
);

-- 推广链接表
CREATE TABLE promotion_links (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  promoter_id UUID REFERENCES profiles(id),
  tool_id UUID REFERENCES tools(id),
  code TEXT UNIQUE NOT NULL,
  click_count INTEGER DEFAULT 0,
  conversion_count INTEGER DEFAULT 0,
  commission_earned DECIMAL(10,2) DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW()
);
```
